# ShopMaster — Веб-приложение для учета товаров и продаж в магазине

**ShopMaster** — это легкая, быстрая и автономная система учета товаров, кассовых продаж и финансовой аналитики, разработанная для личного использования и не требующая установки тяжелых серверов или баз данных.

---

## 🚀 Как запустить?

Просто откройте файл `index.html` в любом браузере (Google Chrome, Яндекс.Браузер, Microsoft Edge, Safari):
- Запустите `index.html` двойным кликом мышкой.

Все данные автоматически сохраняются прямо в вашем браузере (**LocalStorage**), так что ничего не потеряется даже при закрытии страницы или перезагрузке компьютера.

---

## 📋 Основной функционал

### 1. 📊 Дашборд и Главные показатели
- Выручка (Общая сумма продаж).
- **Чистая прибыль** (Выручка минус Себестоимость закупленных товаров).
- Общая стоимость всех товаров, находящихся на складе.
- Количество проведенных чеков.
- Уведомления об остатках (warning-баннер, если товар заканчивается).
- Топ-5 лидеров продаж.

### 2. 🛒 Кассовый терминал (POS)
- Быстрый выбор товаров кликом по карточкам или поиск по названию/штрихкоду.
- Фильтрация товаров по категориям.
- Формирование корзины с подсчетом суммы и возможностью указать **Скидку (%)**.
- Выбор способа оплаты (Наличные, Карта, Перевод).
- Нажатие кнопки **"Оформить продажу"**:
  - Автоматически **списывает товар со склада**.
  - Начисляет выручку и чистую прибыль.
  - Формирует и выводит на экран **кассовый чек** с возможностью распечатать.

### 3. 📦 Склад и Товары
- Добавление новых товаров (Наименование, Категория, Штрихкод/Артикул, Закупочная цена, Продажная цена, Количество, Иконка-эмодзи).
- Редактирование и удаление товаров.
- Быстрое пополнение остатка (+10 шт) прямо из таблицы.
- Автоматический расчет рентабельности/маржи каждого товара в %.

### 4. 🧾 История продаж и Возвраты
- Просмотр всех чеков.
- Возврат продажи (при нажатии кнопки **"Возврат"** товары автоматически возвращаются на склад, а сумма чека и прибыль списываются).

### 5. ⚙️ Настройки и Резервное копирование
- Настройка названия магазина и знака валюты (₽, $, сум и т.д.).
- **Экспорт бэкапа (JSON):** скачивание файла резервной копии всех ваших товаров и продаж на случай перегрузки компьютера.
- **Импорт бэкапа (JSON):** мгновенное восстановление всех данных.
- **Тёмная / Светлая тема.**
